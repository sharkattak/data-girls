# Clarity Hub

**Simplifying research, making data accessible for all.**
Clarity Hub is an innovative educational platform designed to make learning easier and more engaging. It combines an AI Tutor chatbot with educational videos, glossaries, and interactive quizzes to help learners understand complex topics and develop their knowledge.

## About the Project
In an era of overwhelming information and online distractions, finding reliable and accessible learning resources can be challenging. Clarity Hub aims to simplify the learning process by providing a low-barrier educational experience that supports learners throughout their educational journey.
The application currently focuses on Object-Oriented Programming (OOP), providing users with learning resources and opportunities to test their understanding through interactive quizzes.

## Features
### AI Tutor Chatbot
The AI Tutor allows users to interact with an educational chatbot through a simple chat interface. Users can enter questions or keywords to access learning resources.
The chatbot currently supports:
* Object-Oriented Programming (OOP)
* Educational video recommendations
* Glossaries of important terms

### Educational Videos
Users can request an educational video about Object-Oriented Programming. The video is embedded directly into the application, allowing learners to study without leaving the platform.

### Interactive Glossary
The application provides a glossary of key OOP concepts, including:
* Abstraction
* Inheritance
* Polymorphism
* Encapsulation
* Classes and objects
* Methods and properties
* Getters and setters
The glossary helps learners revise important terminology and understand fundamental programming concepts.

### Interactive Quizzes
Clarity Hub includes quizzes designed to test the learner's understanding of the educational content.
The quiz system:
* Presents questions about OOP concepts.
* Allows learners to submit answers.
* Tracks the number of attempts made for each question.
* Moves through different topics as questions are answered correctly.
* Displays learning metrics when all quizzes are completed.

### Learning Metrics
Once a learner completes all the available quizzes, the application displays a summary of their attempts for each question. This allows learners to reflect on their progress and identify areas where they may need further practice.

## Technologies Used
* **HTML5** – Provides the structure and content of the application.
* **CSS3** – Handles the layout, styling, chatbot interface, and overall appearance.
* **JavaScript** – Powers the chatbot interactions, educational content, quiz functionality, timers, and learning metrics.
* **YouTube Embed** – Allows educational videos to be displayed within the application.

## How to Run the Application
1. Download or Clone the Repository
Download the project files or clone the repository to your computer.
2. Open the Project
Ensure that the HTML, CSS, JavaScript, and logo files are located in the same project folder.
3. Launch the Application
Open `clarityHub.html` in a web browser.
Alternatively, use a local development server such as the Live Server extension in Visual Studio Code.
### 4. Explore the Features
Once the application is open:
1. View the Clarity Hub homepage.
2. Open the AI Tutor.
3. Request an OOP video or type `glossary`.
4. Watch the educational video.
5. Complete the interactive quizzes.
6. View your learning metrics after completing the available questions.

## Example Chatbot Commands
| User Input                    | Application Response                                             |
| ----------------------------- | ---------------------------------------------------------------- |
| `OOP`                         | Displays an educational video about Object-Oriented Programming. |
| `object oriented programming` | Displays the OOP video and a glossary option.                    |
| `video`                       | Displays the educational video.                                  |
| `glossary`                    | Displays a glossary of key OOP terms.                            |

## Current Limitations
Clarity Hub is currently a front-end educational prototype. The chatbot responds to specific keywords rather than using a live AI model or natural language processing system.
Other current limitations include:
* The available learning content focuses on Object-Oriented Programming.
* Quiz answers must match the stored answers exactly, apart from differences in letter case.
* Learning metrics are displayed within the current session.
* There is no user account or database system for saving progress.
* The application requires an internet connection to load the embedded YouTube video.

## Future Improvements
Future development could include:
* Integrating a real AI chatbot for more flexible and personalized responses.
* Adding more educational topics and learning resources.
* Improving quiz answer checking to accept equivalent answers.
* Introducing user accounts and saved learning progress.
* Adding more detailed performance analytics.
* Improving the application's responsive design for mobile devices.
* Expanding the glossary and educational video library.

## Project Mission
Clarity Hub aims to create a collaborative and supportive learning environment where learners can access educational resources, test their understanding, and build confidence in their abilities.
By combining accessible learning materials with interactive features, the platform seeks to make education more engaging and enjoyable for everyone.
